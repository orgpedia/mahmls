This directory is not part of the document flow but contains code written to do the following

1. Download the documents present in the websites directory.
2. Code to generate the documents.yml

Code Files
1. build_documents.py: Old python file  - NOT NEEDED
2. check_url.py: Quickly check if the url is working or not
3. create_yaml_from_directory.py: creates documents.yml form PWD
4. download_page_pdf.py: Reads a url/html_path and saves the pdf files in the directory
5. download_playlist_video.py/download_playlist.py: File for downloading youtube vidoes
6. getLinks_with_string.py: Download links from a html file - NOT NEEDED
7. getPDFLinks.py: Download pdf files in a url - NOT NEEDED
